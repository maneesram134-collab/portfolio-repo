# Personal Portfolio Website

An interactive, visually dynamic portfolio website showcasing my skills, projects, and professional information. Built with HTML, CSS, JavaScript, and Bootstrap, featuring custom animations, canvas visualizations, and fully responsive design.

## 🚀 Live Demo

**[View Live Portfolio](https://maneesram.netlify.app/mobile%20friendly%20portfolio.html)**

*(Alternative: [GitHub Pages Link](https://maneesram134-collab.github.io/Task1-portfolio-repo/))*

## 📋 Features

### Profile Section
- **Animated Profile Image** - Floating animation with glowing hover effect
- **Typing Effect** - Rotating professional titles (Full Stack Developer, Data Analyst, AI/ML Developer)
- **Professional Summary** - Detailed introduction about Data Science background
- **Education Details** - College (B.Sc with 88%) and school (Kendriya Vidyalaya with 80%)

### Skills Display
- **Skills List** - Comprehensive text listing of programming languages, web development, databases, data science tools
- **Skill Cards** - Visual cards for Full Stack Developer, Data Analyst, and Dashboard Technologies
- **Skills Network Visualization** - Custom canvas animation showing 14 skills with percentage bubbles
- **Average Skill Calculation** - Dynamic average (61%) displayed below visualization

### Projects Section
- **Project Cards** - AI Image Generation, Mail Validation, Calculator, Rock Paper Scissors, Translator, Text Summarization
- **Oasis Infobyte Projects** - AI Mail Chat, Billing System, AI Chat Bot, Location Tracker, Weather Dashboard
- **Internship Projects** - Exam Hall Seating Allotment System
- **Image Hover Effect** - Images expand on hover for better viewing

### Advanced Visual Effects
- **Floating Words Background** - 20 words (JavaScript, Python, HTML, CSS) floating with different animation speeds
- **Blinking Stars** - 100 stars randomly placed with twinkling animation
- **Mouse Trail Effect** - Blue dots follow mouse movement
- **Animated Gradient Background** - Smooth color transitions
- **Scroll Animations** - Elements fade in as they enter viewport

### Navigation & UI
- **Dual Section Interface** - Toggle between Profile and Projects views
- **Smooth Transitions** - Fade animations when switching sections (800ms)
- **Contact Button** - Direct link to Google Form
- **Fully Responsive** - Works on desktop, tablet, and mobile

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Semantic page structure |
| CSS3 | Styling, animations, gradients, keyframes |
| JavaScript ES6+ | Canvas animations, event handling, interactivity |
| Bootstrap 5 | Responsive grid and components |
| jQuery | Simplified DOM manipulation |

### Key Features
- **Canvas API** - Skills Network Visualization with animated bubbles
- **Intersection Observer** - Scroll-based animations
- **CSS Animations** - Floating words, blinking stars, transitions
- **Media Queries** - Mobile responsiveness at 767px breakpoints
